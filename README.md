# Full-Stack E-Commerce Platform

A modern full-stack e-commerce application built with React, Spring Boot, PostgreSQL, Cloudinary, Render, and Vercel.

This project demonstrates a complete cloud-deployed shopping platform with product management, image uploads, shopping cart functionality, transactional checkout flows, and purchase history tracking.

# Live Demo

URL: https://ecommerce-lyart-two-19.vercel.app/

# Features

## Product Marketplace
- Browse available products
- Search products by name or description
- Filter products by category
- Responsive product grid UI

## Product Management
- Create products
- Edit products
- Delete products
- Upload product images
- Cloud image hosting with Cloudinary

## Shopping Cart
- Add products to cart
- Quantity management
- Persistent cart storage using localStorage
- Cart synchronization with live inventory

## Checkout System
- Transactional checkout processing
- Inventory validation
- Stock updates after purchase
- Automatic removal of sold-out products

## Transaction History
- Persistent purchase history
- Historical transaction snapshots
- Itemized purchase records

## Authentication
- User registration
- User login
- Session persistence using localStorage

# Architecture & Tech Stack

## Frontend
- React
- Vite

## Backend
- Spring Boot REST API
- JPA/Hibernate ORM
- RESTful API architecture

## Database
- PostgreSQL hosted on Neon

## Cloud & Deployment
- Vercel (frontend hosting)
- Render (backend hosting)
- Docker (containerization)
- Cloudinary (image hosting)
